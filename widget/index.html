oe-review-widget

Live demo — no backend

A drop-in reviewer checklist + feedback overlay. This page loads it with an inline checklist and no server: open the Review tab in the bottom-right corner, mark steps pass/fail/n-a, add a note, then hit Download review report — you get a Markdown + JSON pair to paste into Claude for triage.

Everything runs client-side. The checklist below is embedded in this page; swap it for data-src="…/your-checklist.json" to load one from any URL instead.

Embed it on any page:

<script src="oe-review-widget.js"
        data-instance="demo"
        data-label="Widget demo"
        data-src="https://example.org/uat-demo.json"></script>
